# Who's the Beast Chef? / 谁是大厨生

> `v0.0.2` Prototype 0.6A Resource Loop Update — Godot 4.6

《谁是大厨生》是一款 2D 俯视角实时烹饪 × 战斗原型。

玩家需要在同一片场地中处理食材、使用不同锅具制作料理，并把料理转化为远程攻击、近战武器或诱食陷阱，在照看厨房的同时帮助来袭的“味真族”完成复味。

当前版本用于验证：**烹饪能否成为持续影响战斗局势的核心资源。**

## 当前可玩内容

- 自由准备后主动“开始营业”，连续完成三波 Prototype 战斗。
- 五格快捷栏与 `6×6` 异形背包，保存真实物品、锅具、料理品质、调味和耐久状态。
- 可旋转异形网格仓储：正式本局使用 `10×8` 实际库存柜，自由大厅提供可滚动 `20×20` 全物品无限测试目录。
- 普通与重型味真族会生成需要玩家亲自拾取的实体战利品；快捷栏满后自动尝试收入背包。
- 一块整牛肉可加工为三块独立牛排，每块可继续切成一份五片牛肉片包。
- 两个通用灶位与三种可搬运锅具：炒锅、煎锅、汤锅。
- 三条代表性牛肉路线：
  - 小炒黄牛肉：摆盘后释放普通公牛；完美品质拥有大型暴怒公牛终结效果。
  - 战斧牛排：翻面 QTE、近战扇形挥砍、可选摆盘与完美大骨头。
  - 涮牛肉：一份牛肉片分为五片，制成可部署的诱食陷阱。
- 盐与芥末主动调味、失败标签、四档料理品质、盘子与清洗循环。
- 普通与重型两种味真族、玩家生命值、分批刷怪和三波连续测试。
- 第一代静态 Prototype 美术；仍保留部分 Debug 色块、文字和临时 UI。

## 操作方式

| 输入 | Prototype 操作 |
|---|---|
| `WASD` | 移动 |
| `E` | 主要交互 / 持续加工 / 翻面 |
| `F` | 投料、拿取或放入当前物品 |
| `R` | 拿取或放回锅具 |
| `Q` | 丢下当前快捷栏物品 |
| 鼠标滚轮 / `1`—`5` | 切换五格快捷栏 |
| `Space` | 开始摆盘 / 确认摆盘 QTE |
| 鼠标左键 | 使用当前战斗料理；部分料理支持按住连续攻击 |
| `G` | 放置涮牛肉诱食陷阱 |
| `M` | 为符合条件的料理加入芥末 |
| `B` | 开始营业 / 波间提前开始下一波 |
| `ESC` | 暂停 / 继续；可确认退出本局 |
| `F3` | 显示或隐藏开发辅助 UI |
| `F9` | 编辑器开发模式下打开试玩记录 |
| `Tab` | 打开或关闭异形背包 |
| 拖拽时 `R` | 旋转背包 / 柜子中的异形物品 |
| `T` | Debug 重置当前测试局 |

以上均为 Prototype 临时键位，尚未提供手柄、键位重映射或正式新手教程。

## 运行项目

推荐使用 **Godot 4.6.2 stable**。

1. 克隆或下载本仓库。
2. 使用 Godot 导入并打开 `GodotProject/project.godot`。
3. 按 `F6` 运行当前主场景，或按 `F5` 运行项目。
4. 场景载入后可以立即自由准备；点击画面右上区域的“开始营业”后敌人才会来袭。

主场景：`GodotProject/Scenes/prototype_0_1/main.tscn`

## 当前状态与限制

这是开发中的公开测试版本，不是完成版：

- 玩法数值、操作、地图和 UI 均为 Prototype 临时方案。
- 尚无正式音效、存档、设置菜单、手柄支持和完整教程。
- 部分物品、攻击实体、地图细节和界面仍使用灰盒占位表现。
- 自动化测试已覆盖 Prototype 0.1 至 0.6A，但操作手感、数值、仓储空间压力和音频体验仍需要持续人工试玩。
- Windows 免安装测试包可从 [v0.0.2 Release](https://github.com/CXuze0605/WhoIsTheBeastChef/releases/tag/v0.0.2) 下载；解压后保持 `.exe` 与 `.pck` 同目录。

## 项目结构

- `AI_Context/`：设计决定、开发状态、实现记录和 AI 协作交接文档。
- `GameDesign/`：核心玩法文档、设计草稿、数值表和美术需求。
- `GodotProject/Assets/`：Prototype 美术与后续游戏资源。
- `GodotProject/Scenes/`：Godot 场景。
- `GodotProject/Scripts/`：GDScript 玩法代码与自动化测试。
