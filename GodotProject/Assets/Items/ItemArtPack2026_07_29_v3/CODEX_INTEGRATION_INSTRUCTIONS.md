# 给 Codex 的修复指令：补全物品美术映射

## 背景

上一版美术包 V2 误把 39 张可用素材归入 `review_required`，并要求不要接入，因此测试大厅
全物品柜中仍有大量物品只显示彩色异形占格。这是素材包分类错误，不是这些物品没有素材。

请使用本 V3 包修复。不要继续遵循 V2 中“跳过 original_batch_candidates”的规则。

## 任务范围

1. 读取当前最新工程中的：
   - `AI_Context/Current_Status.md`
   - `AI_Context/AI_Handoff.md`
   - `AI_Context/Pending_Tasks.md`
   - `AI_Context/Decision_Log.md`

2. 检查当前实际的 `ItemData`、`ItemCatalog`、美术目录、背包/柜子图标映射与手持显示映射。
3. 以 `ASSET_MANIFEST.csv` 为主要对照，把 `assets/ready/**` 中的 60 张素材全部复制到工程统一
   的物品美术目录。
4. 对当前已存在的 ItemType，按物品中文名、状态和清单中的预期映射完成注册。不要因为清单仍写有
   `future item` 就跳过：如果当前工程已经实现了该物品，应当立即映射。
5. 未装盘和已装盘必须映射为不同图片；普通品质与完美品质沿用当前品质逻辑，不要擅自增加新玩法。
6. 测试大厅全物品柜、玩家背包、五格快捷栏、手持物和地面掉落物必须共用同一套映射来源。
