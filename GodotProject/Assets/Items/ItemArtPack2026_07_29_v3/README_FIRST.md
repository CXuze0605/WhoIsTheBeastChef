# 《谁是大厨生》物品美术接入包 V3

这是修正后的正式接入包。V2 的分类过于保守，把 39 张已经对应当前物品的素材放进了
`review_required`，导致接入后仍显示大量彩色占格。V3 已撤销这一错误分类。

## Codex 应当使用什么

- `assets/ready/**`：正式接入目录，共 60 张，可按清单映射。
- `ASSET_MANIFEST.csv`：机器可读的一一对应表。
- `ASSET_MANIFEST.md`：人工核对表。
- `CODEX_INTEGRATION_INSTRUCTIONS.md`：直接交给 Codex 的修复指令。

## Codex 不应当直接使用什么

- `assets/needs_processing/**`：仅有完美战斧牛排母图，灰底尚未抠除，不能直接导入。
- `assets/sources_48px/**`：保留用于以后重绘的高分辨率母版，不是游戏内最终图。
- 本包没有收录失败重绘稿、被替代版本或原批次的未选中备选图。
