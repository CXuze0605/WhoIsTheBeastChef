# 米饭、青菜与牛肉组合料理内容扩展

> 授权日期：2026-07-28  
> 当前公开版本：v0.0.2 / Prototype 0.6A  
> 当前未发布代码基础：Prototype 0.6B  
> 文档状态：大型内容扩展实施依据。完成状态必须以本文“里程碑状态”和 `Current_Status.md` 为准；设计归档不等于代码已经实现。

## 1. 目标与范围

本轮在 0.6A 真实物品实例、异形背包 / 柜子和掉落闭环，以及 0.6B 护盾、速度 / 远程敌人、米袋、白饭、白粥和锅巴基础上，建立米饭、青菜、牛肉组合料理体系。

核心目标：

- 少量基础食材通过工序、加入顺序和料理形态形成明显不同的战斗选择；
- 共用数据驱动配方、伤害来源、状态、品质上限、耐久、部署物、炮台和自动装备基础；
- 保留五格快捷栏、真实物品实例、异形背包、局部模态、正式新局隔离和既有三波流程；
- 所有数值为集中、可调的 Prototype 参数，不宣称完成商业平衡。

明确不做：联机同步、猪肉 / 青菜瘦肉粥、新鲜度 / 腐败 / 冰箱完整系统、新角色、怪异料理突破完美、未列出菜品、正式美术 / 动画 / 音效、无关架构重写、Git 发布操作。

## 2. 共用系统

### 2.1 料理与物品实例

`ItemData` 继续是单份真实物品的权威数据，补充：

- 配方身份、食材份数、食材加入顺序、离散烹饪节点；
- 失败标签、主动调味、怪异料理、品质上限；
- 耐久、已使用、部署 / 自动装备开关；
- 来源料理实例与关联目标 ID；
- 菜叶数、牛肉组状态、腌制状态等配方参数。

配方关键食材和核心工序决定料理身份；普通调味只修改属性。同一组现实合理的加入顺序可得到同一道料理，推荐顺序只影响完美资格。失败标签不会被组合或摆盘清除。原料不足、输出无空间或组件已使用时必须原子失败。

### 2.2 伤害来源

统一来源类别：

| 来源 | 是否可吃玩家直接攻击增幅 |
|---|---|
| 玩家直接近战 | 是 |
| 玩家直接远程 | 是 |
| 炮台 | 否 |
| 召唤物 | 否 |
| 陷阱 | 否 |
| 持续伤害 | 否 |
| 状态触发伤害 | 否 |
| 自动料理装备 | 否 |
| 环境伤害 | 否 |
| 友军伤害 | 由实际来源决定，默认否 |

伤害上下文保存来源实体、来源料理实例、来源类型、基础伤害、目标阵营、友伤、直接攻击增幅资格、状态影响资格，以及实际护盾 / 生命伤害。

结算顺序：基础与品质 → 合法直接攻击增幅 → 攻击者虚弱 → 目标易伤 → 目标免伤 / 锅巴 → 护盾 → 生命 → `RunStats` 实际记录。倍率默认乘算。

### 2.3 通用状态

共用状态包括：移速降低、攻速降低、虚弱、易伤、失瞄、短僵直、击退、持续生命恢复、直接近战 / 远程增幅、免伤、热食和怪异料理携带诅咒。

同类普通状态默认取最高强度；每个来源使用独立来源 ID 和持续时间。移除一个来源不能清除其他来源。明确允许多份自动料理形成构筑的效果不通过隐藏上限取消。随机状态使用可注入随机种子。

### 2.4 品质与怪异料理

- 品质仍为完美、正常、瑕疵、糟糕；
- 普通料理无失败标签且摆盘 QTE 完美才可完美；
- 未摆盘最高正常；使用过任何耐久后永久失去摆盘资格；
- 组合继承组件全部失败标签与最低品质上限；
- 怪异料理不是失败料理，但当前品质上限固定为正常；
- 怪异料理没有完美最后一击；未来角色突破只保留数据接口。

### 2.5 主动炒制与移动 QTE

- 煎、煮、蒸和普通加热继续自动推进；
- 炒锅中的有效炒制阶段必须由玩家站在锅前持续按住交互键推进；
- 松开不强制锁人，当前阶段按集中参数决定归零 / 保留；
- 开火离开过久只增加焦糊风险，不自动完成炒菜；
- 主动炒制时玩家不能移动、攻击或处理其他设施；
- 炝炒阶段完成后出现短 QTE；失败只重置当前炒制段，不返还油、辣椒和青菜；
- 拆菜和摆盘 QTE 世界继续运行，允许 WASD，锁攻击 / 切换 / 交互 / 丢弃；ESC 先取消。

## 3. 食材加工

### 牛肉

`整块牛肉 3×3 → 三块独立牛排 1×3 → 每块一组牛肉片 1×1（5 份） → 一组牛肉丁 1×1`。

切丁不增加肉量。腌制可发生在切丁前或后并保留。三牛排、切片和切丁均要求输出位置预检，不吞原料。

### 青菜

整颗青菜可在任意地点通过移动 QTE 拆为固定 5 片 `1×1` 青菜叶。菜叶可有限堆叠。拆分失败不减少产量；输出空间不足不消耗整颗青菜。

### 米袋与水

米袋 `3×4`、可旋转、Prototype 20 份；内部数量属于实例。每次只生成一份 `1×1` 生米，成功进入快捷栏、背包或合法地面后才扣数量。水池免费供水；水只作为锅具 `0/1/2` 离散状态。

## 5. 关键料理规则

### 盐水青菜

敌人进入近距离警戒范围时，最近单体触发击退和极短僵直；同一敌人离开后才可再次触发。多份共用全局冷却。重型效果较弱。完美最后一次改为玩家周围 AOE。

### 回旋与炝炒菜叶

清炒叶去 / 回程对同一敌人各最多一次；辣味第一段命中先结算伤害再施加易伤，回程可受益。炝炒直击伤害，爆点只有失瞄；完美最后一片实际爆开后才对仍呛到的敌人造成状态触发伤害。

### 粥

持续饮用开始预扣耐久，恢复随进度发生，中断不回滚。青菜粥完美最后一份完整喝完后才触发 `1/秒 × 5 秒` Prototype HoT。牛肉粥增幅只影响玩家直接近战 / 远程；炮台、陷阱、DoT、状态触发、自动汤流和大型自动公牛不受益。

### 三种炒饭

- 青菜炒饭：低伤大范围；
- 牛肉炒饭：高伤严格单体；
- 青菜牛肉炒饭：主要目标一次结算，外围低伤；单体和范围分别低于专精版本。

### 菜饭、泡饭与菜泡饭

菜饭部署不消耗耐久，区域内玩家 / 队友按住交互完成一口后才消耗共享耐久并恢复护盾；最后一口完美奖励为短时间免伤。泡饭区域不分敌我，降低地面单位移速 / 攻速；菜泡饭额外降低造成伤害。多区域同类效果取最强，不无限叠加。

### 盖饭炮台

每次实际发射才消耗耐久，无敌人不空射。三发随机袋必含饭团 AOE、穿透青菜、单体牛肉各一发；可注入种子。完美最后一次同时发射三种弹药。炮台伤害不吃玩家直接攻击增幅。首版不赋予敌人主动攻击炮台、炮台生命或正式回收规则。

### 青菜牛肉汤

每份实例独立开启、锁定最近有效目标、转向、伤害 tick、耐久和完美末击；允许 5 份或更多同时运行，不设隐藏数量上限。墙和大型设施阻挡。无目标不喷射、不扣耐久。伤害属于自动料理装备，不吃玩家直接攻击增幅。

### 芥末青菜

怪异料理，最高正常。每片叶命中首个未标记敌人后贴附，零直接伤害；主目标获得虚弱、移速 / 攻速降低和易伤，周围敌人只获得减速 / 易伤。料理在玩家携带库存中时，持有者易伤、最近其他玩家减速。移出携带库存立即解除该来源全部标记和诅咒。最后一片发射后保留残盘，最后关联目标离场才变脏盘。

## 8. 已知风险

- 料理数量明显超过早期 2—3 种代表性验证范围，必须通过共用数据与人工试玩避免变成大量相似图标；
- 主动炒制改变 D-038 的旧自动炒制规则，必须保持煎 / 煮自动和现有两灶三锅流程；
- 多份自动汤与炮台可能造成性能、画面遮挡和被动战斗过强；
- 不分敌我的泡饭区域和芥末携带诅咒需要明确反馈，否则会违反“混乱公平可读”；
- 移动 QTE、实时背包、暂停与 F9 共享输入优先级，必须以真实输入路径回归；
- 当前没有网络多人，只能用玩家 / 友方假人与本地目标接口验证多人语义。
