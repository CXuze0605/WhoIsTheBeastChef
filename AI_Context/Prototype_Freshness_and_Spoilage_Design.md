# 第一版新鲜度、腐败物与浪费强化设计

> 日期：2026-07-30  
> 状态：第一版代码已实现；全部数值仍为 Prototype，需实机调整  
> 公开版本：不变，仍为 `0.0.2 / Prototype 0.6A`

## 1. 目标与范围

本系统在现有真实 `ItemData` 实例、五格快捷栏、异形背包、食材柜、世界掉落、工位、品质、失败标签、掉落补偿和 `RunStats` 上扩展，不建立第二套物品或库存系统。

正式本局中的可腐败物品会随权威局内时钟老化，依次经过新鲜、尚鲜、临期与腐败。临期是永久失败标签；腐败是硬失效状态。腐败物保留原占格和份量，玩家清理或主动放弃食物会累计浪费值，使之后生成的味真族按线性公式持续变强。

本轮不实现冰箱、冷藏倍率实际玩法、堆肥、菜园、局外经济、腐败料理、食用腐败物、空瓶、联机同步或正式腐败美术。

## 2. 已正式确认的规则

- 每个可腐败实例保存精确 `spoilage_ratio`，不能只保存离散枚举。
- 状态阈值：
  - 新鲜：`[0.00, 0.40)`
  - 尚鲜：`[0.40, 0.75)`
  - 临期：`[0.75, 1.00)`
  - 腐败：`>= 1.00`
- 临期对应正式 `FailureTag.NEAR_EXPIRY`，中文固定为“临期”。
- 只有临期标签时品质最高为瑕疵；临期加任意另一失败标签时为糟糕。
- 腐败不是失败标签，而是不可烹饪、摆盘、战斗、部署、食用或恢复的独立硬失效物品。
- 新鲜与尚鲜的同类兼容堆可以按真实接收份数加权平均；临期只与临期合并；所有腐败物完全不可堆叠。
- 只改变形状的加工继承精确腐败比例；腌制完成和料理正式形成刷新当前周期，但永久临期标签不清除。
- 腐败物继承原始占格、异形遮罩和实例旋转方向，不能借腐败压缩空间。
- 垃圾桶清理仍可食用食物或腐败物会结算浪费；主动把腐败物丢地也结算，且每个实例只结算一次。
- 地面可食用物自然腐败时立即结算一次，避免把地面当作免费垃圾区。
- 浪费强化只影响之后生成的味真族，不追溯场上单位或已经进入前摇的攻击。
- 浪费强化没有硬上限，采用从基础值出发的线性计算，不使用指数或复利。

## 3. Prototype 集中数值

### 3.1 保鲜时间

| 类别 | 总保鲜时间 |
|---|---:|
| 整块生牛肉 | 720 秒 |
| 生牛排 | 600 秒 |
| 生牛肉片、生牛肉丁 | 420 秒 |
| 腌牛肉片、腌牛肉丁 | 660 秒 |
| 整颗青菜 | 540 秒 |
| 青菜叶 | 360 秒 |
| 所有未摆盘／已摆盘完成料理及失败料理 | 600 秒 |

集中目录：`FreshnessCatalog`。

### 3.2 浪费强化

每一点 `waste_units`：

- 后续味真族最大生命 `+0.5%`
- 后续味真族直接攻击伤害 `+0.25%`

公式：

```text
health_multiplier = 1.0 + waste_units * 0.005
damage_multiplier = 1.0 + waste_units * 0.0025
```

校验值：

| 浪费 | 生命倍率 | 伤害倍率 |
|---:|---:|---:|
| 40 | 1.20 | 1.10 |
| 100 | 1.50 | 1.25 |
| 200 | 2.00 | 1.50 |

系数可以根据试玩调整，但未经负责人新决定不得恢复硬上限。

## 5. 权威时钟

`FreshnessManager` 位于唯一 Gameplay 主场景根节点。

- 正式开局完成统一重置、进入准备阶段时 `begin_formal_run()`。
- 正式准备、预警、战斗和波间继续。
- `SceneTree.paused` 时节点默认暂停处理，时钟不前进。
- 实时背包、柜子和局部 UI 不暂停时钟。
- 自由大厅不运行。
- 结算前刷新最后区间并停止；返回大厅和新局重置清零。
- 每个实例保存 `freshness_clock_stamp`。每次集中扫描按 `ItemData` 实例 ID 去重，所以同一实例即使被多个入口引用也只老化一次。
- 快捷栏、背包、柜子和工位中的 `CarryableItem` 即使不可见或不执行自己的 `_process()`，仍由集中扫描更新。
- 移动、拾取、旋转、打开界面和放回柜子不重置时间戳。

## 6. 烹饪与工位

- 地面、库存、切菜板、腌制台、未加热锅具、关火锅具和等待摆盘均继续老化。
- 只有“有效锅具 + 开火 + 当前烹饪阶段确实推进”才返回暂停原因，防止把锅当冰箱。
- 食材在切配或腌制中腐败会取消当前 `HoldProgress`；不生成结果。
- 腌制已开始且牛肉在过程中腐败时，已经投入的腌肉料不返还。
- 锅中内容腐败会取消持续处理与 QTE，但腐败物留在锅中，可以按既有取回流程拿走，避免工位软锁。
- 涮牛肉及已部署料理腐败时转为同位置世界腐败物；已释放的攻击实体按生成快照继续，不追溯修改。

## 7. 加工、组合与品质继承

- `ItemCatalog.transform()` 与 `duplicate_data()`复制精确新鲜度、时钟字段、失败标签和腐败快照。
- 整肉→牛排→肉片／肉丁、整菜→菜叶继承相同比例。
- 腌制与生食材→完成料理重置当前比例为 0，但保留临期及其他失败标签。
- 扩展组合料理通过既有 `inherit_recipe_state()` 合并失败标签，摆盘不能清除临期。
- 完美料理后来进入临期时立即重算为瑕疵或糟糕，清除完美最后一击资格；品质相关最大耐久只向下限制当前剩余耐久，不返还已经消耗的耐久。

## 8. 加权堆叠

合并公式：

```text
(A腐败度 × A实际份数 + B腐败度 × 实际接收份数)
÷ 合并后的总份数
```

- 部分接收只把真实接收份数纳入平均；incoming 剩余部分保持原腐败度。
- 合并后视为一个混合批次；再拆分时双方继承同一精确平均值。
- 自动堆叠先筛合法堆，再按腐败度差的绝对值从小到大选择。
- 快捷栏优先、背包后备和拖放原子回滚规则保持不变。
- 永久带有临期标签但通过腌制／成菜刷新周期的物品，仍不能与无临期标签的同类堆合并。

## 9. 腐败物数据快照

腐败时原实例原地变为 `ROTTEN_WASTE`，保存：

- 原 `ItemType`、显示名与美术 key
- 原始未旋转形状遮罩
- 现有 `storage_rotated`
- `waste_units_snapshot`
- 原等价食材份数
- `waste_penalty_settled`

腐败物：

- 强制 `is_stackable=false`、`max_stack_count=1`
- 清空配方身份、组件、主动改造、攻击形式、料理方法、战斗数值、摆盘与部署能力
- UI 使用原来源图片加灰绿色腐败覆盖；没有来源的测试样本使用现有失败牛肉图作为 Prototype 回退
- 背包、柜子、拖放预览、红色落点框和旋转统一读取实例形状

## 10. 浪费值

- 整块牛肉：15
- 生牛排：5
- 肉片／肉丁／菜叶：真实剩余份数
- 整颗青菜：5
- 米袋、油瓶、盐瓶：实例剩余份数
- 完成料理：优先累计 `ingredient_counts`，缺失时使用集中最低值 1
- 锅具、盘子、焦炭、大骨头和测试工具：0

`settle_waste()`先检查实例结算标记；重复拾取、丢弃、垃圾桶清理不会重复累计。

## 11. 味真族与短缺补偿

- `WaveManager` 在普通、速度、重型、远程实例完成自身基础生命和伤害配置后，读取当前共享浪费倍率并快照到新敌人。
- 基础近战、重型攻击、速度冲刺和远程推击／饭团直接攻击均读取该次生成快照。
- 不改变速度、攻速、前后摇、投射物速度、控制、体型、掉落率或掉落表。
- 动态短缺补偿继续使用现有实现，只修正可腐败资源的有效库存：
  - 新鲜／尚鲜：1.0
  - 临期：0.5
  - 腐败：0.0
- 油、盐、生米和米袋继续按真实剩余份数计算。

## 12. UI、调试与统计

- 快捷栏和异形网格使用绿／浅黄／橙／灰绿色边框或覆盖区分四态。
- 悬停显示状态、失败标签、份数、品质；腐败物额外显示浪费份量和是否已经结算。
- F3 调试显示精确腐败度、剩余秒、总周期、暂停原因、来源、累计浪费和当前敌人倍率。
- `RunStats`记录自然腐败数量／份数、腐败物生成、垃圾桶与丢地结算、可用食物丢弃、累计浪费、最终倍率、临期加工／使用和腐败料理损失。

## 14. 尚需人工确认

- 一局真实时长下各 360—720 秒周期是否太宽松或过紧。
- 临期橙框、腐败覆盖和战斗反馈是否足够清楚但不过度遮挡美术。
- 处理 5／15 份腐败物时无上限线性强化的压力增长是否过快。
- 玩家是否会为了避免强化而长期让大形腐败物占据背包，以及该选择是否有趣。
- 部分新鲜批次合并后的提示、自动堆叠优先级和碎片感。
- 正式腐败物美术、音效与完整结算页统计展示。

## 15. 被修正的旧规则

- D-019 中“新鲜度逐渐降低效果”被修正为：新鲜和尚鲜无效果惩罚；临期通过正式失败标签影响品质；腐败完全失效。
- D-019 中“清理腐败物触发浪费并强化味真族”的方向正式恢复落地。
- D-079、D-090 对未经授权实现腐败的限制已被负责人本次明确授权覆盖；冰箱、堆肥、菜园及完整垃圾经济仍未授权。
- 早期“40 点封顶”草案被同一任务的最终修订覆盖。当前浪费强化无硬上限，保持线性而非复利。
