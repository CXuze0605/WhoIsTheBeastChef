# Prototype 0.3.1：战斗节奏、地图规模与烹饪时间调整

> 更新日期：2026-07-20  
> 状态：已实现并通过自动化验收与全量回归  
> 性质：试玩反馈驱动的灰盒调优；本文数值与地图布局均不是最终平衡或正式关卡设计

## 一、本轮试玩反馈

Prototype 0.3 的首轮试玩暴露出五个问题：

1. 18 秒准备时间不足，基础料理前期准备容易被来袭打断。
2. 基础味真族 0.62 秒前摇和 0.48 秒后摇过长，持续移动几乎可以稳定规避攻击。
3. 旧地图可活动范围只有 `910 × 664`，厨房设施占据大部分空间，缺少真正的拉扯区域。
4. 两段自动炒制只有 1.3 秒和 1.4 秒，无法形成“离开灶台处理其他任务”的时间管理体验。
5. 切菜与腌制基本合理，只需要小幅延长。

## 二、本轮正式确认的方向

- 准备阶段需要足够玩家完成一份基础小炒黄牛肉的前期准备，但有限库存、提前营业和不返还资源规则不变。
- 刷怪仍采用全局预警、局部方向预警和分批进入，只放慢批次节奏，不改变本轮六只味真族总数。
- 基础味真族仍是“缓慢逼近 → 可观察前摇 → 锁定方向挥击 → 后摇 → 继续追击”，本轮只缩短前后摇，不增加冲刺、追踪挥击或不可躲避攻击。
- Prototype 测试地图需要明显独立的战斗空间；厨房与战斗发生在同一连续场地。
- 自动烹饪需要给玩家离开灶台战斗、取菜、洗盘或调整快捷栏的时间。
- 烹饪中断、离散阶段、投料保留、焦糊和焦炭规则不因调时而改变。
- 地图扩大后需要可读的厨房状态反馈。0.3.1 当时采用远距离屏幕文字；该具体方案已在 0.3.2 按试玩反馈替换为局部环形厨具提示与扩大视野。

## 四、地图扩大与临时厨房布局

### 1. 地图范围

- 旧可活动范围：`Rect2(28, 28, 910, 664)`。
- 新可活动范围：`Rect2(28, 28, 1820, 1328)`。
- 宽度与高度各为旧版 2 倍，总面积为旧版 4 倍。
- 新相机边界：左 `28`、上 `28`、右 `1848`、下 `1356`。
- 新导航范围：`Rect2(42, 42, 1792, 1300)`，继续使用 32 像素 AStar 灰盒网格。

### 2. 厨房临时布局

保留六类厨房设施的旧相对布局，将整个 `Kitchen` 节点临时平移至 `(240, 220)`：

| 对象 | 新全局灰盒位置 |
|---|---|
| 食材柜 | `(710, 325)` |
| 切菜板 | `(395, 540)` |
| 腌制区域 | `(625, 540)` |
| 炒锅工位 | `(865, 540)` |
| 干净盘子堆 | `(1080, 332)` |
| 水池 | `(1080, 540)` |
| 玩家出生点 | `(710, 745)` |

厨房右侧和下方留出大块连续战斗区域；玩家可以绕怪、调整公牛攻击方向，并沿开放路线返回厨房。该布局只服务当前灰盒测试。

### 3. 相机、边界和公牛

- 玩家场景新增 `Camera2D`，启用平滑跟随并读取统一地图边界。
- 四个世界边界碰撞扩到新地图边缘，玩家与味真族不能离场。
- 普通公牛的离场检测和大型暴怒公牛的反弹边界改为读取 `PrototypeCombatConfig.combat_bounds`，不再硬编码旧单屏坐标。

### 4. 导航和出生点

- `PrototypeMapController` 在运行时把统一地图参数应用到地面、边界、厨房、导航、相机、战斗边界和出生点。
- 六个厨房实体障碍继续从真实碰撞矩形生成 AStar 禁行区。
- 八个候选出生点移动到新地图真实边缘：
  - 左侧：`(58, 360)`、`(58, 1024)`
  - 右侧：`(1818, 360)`、`(1818, 1024)`
  - 上侧：`(483, 58)`、`(1393, 58)`
  - 下侧：`(483, 1326)`、`(1393, 1326)`
- 最低出生距离、合法导航路径、设施避让和现有敌人分离规则继续生效。

## 五、远距离烹饪反馈（已由 Prototype 0.3.2 修正）

0.3.1 曾新增可替换的 `CookingStatusUI`：

- 第一阶段完成时提示“需要加入辣椒段”。
- 成菜时提示及时取出。
- 焦糊警告阈值到达时闪烁提示。
- 已焦糊、变成焦炭和无油粘锅事故均有明显提示。
- 玩家距离炒锅超过 360 像素且锅内存在活动状态时，显示厨房方向箭头和当前状态。
- 反馈使用 CanvasLayer、色块和默认字体，不属于正式 UI 或正式音效。

以上是 0.3.1 的历史实现。Prototype 0.3.2 已删除 `CookingStatusUI`，普通烹饪改由炒锅上方世界空间环形提示表达；全局来袭、波次完成和玩家失败提示不受影响。

## 六、保留的既有规则

- 关火、取出料理或拿走炒锅会清空当前未完成阶段进度。
- 已完成离散阶段不倒退。
- 已加入辣椒、盐和其他实际投料不会返还或消失。
- 盐不重置炒制时间；盐与芥末仍独立于失败标签。
- 第一阶段完成且未加辣椒时继续停留在等待投料状态，不新增失败标签。
- 成菜留在开火锅中才会进入焦糊和焦炭。
- 进入预警、刷怪、受击或波次结束不会暂停自动烹饪。
- 有限库存、提前营业记录、当时的三格快捷栏、摆盘、盘子、毒伤和粘锅清洗规则均不改变。快捷栏容量已在 0.3.2 调为五格。

## 九、已知问题与尚未确定

### 已知问题

- AStarGrid2D 仍是灰盒静态导航；正式复杂地形可能改用导航多边形。
- 0.3.1 的远距离文字、色块和方向箭头已在 0.3.2 移除；当前局部环形提示仍没有正式空间音效或美术图标。
- 当前相机未针对正式 HUD 安全区、镜头震动或多人视野进行设计。
- 更大地图会使远边缘敌人的接近路程明显增加，需要人工试玩判断移动速度是否仍合适；本轮按要求未修改敌人移动速度和总数。

### 尚未确定

- 正式地图尺寸、形状和主题。
- 厨房最终位于中央、边缘还是采用分散工位。
- 正式相机行为和来袭/厨房提示表现。
- 准备、刷怪、攻击、切配与炒制的最终数值。
- 提前营业奖励和正式波次奖励。

本轮不得被解释为已经确认最终地图布局或最终平衡。
