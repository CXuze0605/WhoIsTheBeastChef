# Prototype 0.6B：护盾、持续生命、速度 / 远程味真族与米饭路线

> 日期：2026-07-25  
> 状态：Prototype 0.6B 实施依据。机制方向、Prototype 临时数值和尚未确定内容必须分开理解。  
> 前置：Prototype 0.5.1 的正式开局隔离与模态输入修复、Prototype 0.6A 的五格快捷栏、异形背包、真实柜子、实际物品实例、实体掉落和正式重置继续有效。

## 1. 本阶段目标

0.6B 在既有资源循环上增加两类战斗压力和一条米饭资源路线：

`持续生命 + 可恢复护盾 → 速度 / 远程敌人改变站位压力 → 米袋逐份取米 → 加水烹饪 → 白米饭远程续航 / 白粥恢复 / 锅巴防具与碎片陷阱`

实施分为 A—H，每一阶段完成针对性验证后再进入下一阶段，不重写现有背包、波次、烹饪、暂停或伤害架构。

## 2. 正式确认的机制方向

- 玩家增加自动恢复护盾。护盾承担短期容错，生命是跨波次的重要资源；生命不自然恢复，也不因波次结束自动回满。
- 伤害先经过当前锅巴减伤，再扣护盾，溢出部分扣生命。既有敌人和友军伤害统一进入同一玩家伤害入口。
- 新增速度型和远程型味真族，但“赶饭客”“撒味客”均只是内部暂名，不是正式名称。
- 米袋是 `3×4`、可旋转的专属批量资源包装。剩余生米数量属于具体米袋实例，不创建通用嵌套容器。
- 一份生米加一份水煮成白米饭；一份生米加两份水煮成白粥；白米饭继续加热形成锅巴，锅巴继续过热才获得焦糊结果。
- 白米饭是单体、无穿透、高续航的轻量远程武器；白粥是需要安全时间、实时恢复生命的专职恢复料理。
- 白粥读条受到普通伤害会中断，已经恢复的生命不回滚。刚出锅的白粥具有独立“滚烫”临时状态，强行饮用会触发 Prototype 烫伤。
- 锅巴位于快捷栏或玩家背包时自动生效；多个锅巴减伤不叠加，只按稳定顺序依次接替。
- 锅巴破碎后在玩家位置生成一次性锅巴碎陷阱。陷阱具有友军伤害，触发一次后消失。
- 标准战斗料理未来允许用大量耐久进行低效率应急回血；白粥继续使用专属恢复逻辑，怪异料理默认不加入通用应急进食。

## 3. Prototype 集中临时参数

以下数值只用于当前试玩，必须集中配置或导出，不是最终平衡：

### 玩家护盾

- 最大护盾：30。
- 受击后延迟：4 秒。
- 恢复速度：每秒 10 点。
- 波次结束或下一波正式开始前恢复满护盾，生命保持原值。

### 速度型味真族

- 生命约为基础味真族的 60%。
- 常规速度为基础味真族的 1.4—1.5 倍。
- 冲刺伤害 18；蓄力约 0.6 秒；冲刺约 0.3—0.4 秒。
- 落空后摇约 0.7 秒；撞设施约 1 秒；命中玩家约 0.5 秒；冷却约 2.5—3 秒。
- 同场建议上限 4。

### 远程型味真族

- 生命约为基础味真族的 80%，速度略低于基础味真族。
- 投射物伤害 10；近身推击伤害 8。
- 瞄准约 0.8—1 秒；射击间隔约 2—2.5 秒；连续 2—3 发后换位。
- 近身推击前摇约 0.4 秒，随后约 1 秒硬直。
- 同场建议上限 2。

### 米饭路线

- 完整米袋：`3×4`，不可堆叠，初始 20 份生米。
- 生米：`1×1`，本轮不堆叠。
- 一水 + 一米约 8 秒形成待摆盘白米饭。
- 两水 + 一米约 12 秒形成待摆盘白粥。
- 白米饭继续加热约 5 秒形成待摆盘锅巴；锅巴再过热约 4 秒获得焦糊结果。
- 白米饭耐久 12，攻击间隔约 0.3 秒，射程约为普通小炒的 1.3 倍，基础伤害取普通公牛直接伤害约三分之一并独立配置。
- 白粥基础耐久 2，每份饮用 2 秒；完美 / 正常 / 瑕疵 / 糟糕每份治疗暂为 12 / 10 / 8 / 5。
- 白粥滚烫时间 10 秒；每开始饮用一份滚烫白粥，约 2 秒内造成总计 4 点直接生命烫伤，最低保留 1 点生命。
- 锅巴形状 `3×3`、不可堆叠、基础耐久 5；完美 / 正常 / 瑕疵 / 糟糕减伤暂为 35% / 25% / 15% / 10%。
- 锅巴碎陷阱伤害 20，布置约 0.5 秒。
- 通用应急进食：治疗 5、约 1.25 秒、开始时预扣最大耐久 50% 向上取整；实际耐久不足时按支付比例降低最大治疗。

### 掉落

- 普通怪仍沿用约 35% 的一次性实体掉落判定。
- 速度型权重：油 35、辣椒 30、腌肉料 20、盐 10、芥末 5。
- 远程型权重：盐 35、芥末 25、腌肉料 20、辣椒 15、油 5。
- 重型味真族在原保证整块牛肉之外，临时有 10% 概率额外掉落一个完整米袋；每局额外米袋最多 1 个。此规则是正式精英尚未开发前的临时替代。

## 4. 阶段 A：玩家护盾与持续生命

- `max_health` 沿用现有配置；新增 `max_shield` 与 `current_shield`。
- 玩家受到有效伤害时先请求锅巴减伤，再扣护盾，再由溢出扣生命。
- 再次受伤立即停止恢复并重置“距离上次受伤 4 秒”的等待。
- 护盾计时使用游戏处理时间：真正暂停时停止；背包和柜子等实时 UI 不暂停计时。
- 波次切换只恢复护盾；正式新局同时恢复生命和护盾。
- HUD 同时显示生命和护盾，并以文字 / 边框 / 闪动等非单纯颜色方式区分护盾受击、破碎、开始恢复和回满。
- 白粥烫伤使用独立的 Prototype 直接生命入口，不经过护盾和锅巴，也不升级为全局伤害原则。

## 5. 阶段 B：速度型味真族

内部枚举 / 类名可使用 `FAST_ENEMY`，界面暂名“赶饭客（暂名）”。

状态循环：

1. **追赶**：快速接近，不产生接触伤害，不持续贴身平砍。
2. **冲刺蓄力**：进入中短距离后停下，显示身体压低、地面方向和声音；后半段锁定方向。
3. **冲刺**：直线且不可转向，一次冲刺对同一目标最多伤害一次；被墙、灶台、柜台等实体阻挡，不穿出导航区域。
4. **后摇**：按落空、撞设施、命中玩家采用不同短硬直，然后进入冷却。

战斗互动：

- 战斧命中蓄力阶段可取消冲刺；既有僵直可延迟动作，不增加复杂韧性条。
- 涮牛肉诱饵在锁向前权重高于玩家；锁向后本次冲刺不再转向。撞击诱饵会消耗诱饵耐久。
- 从边缘错峰生成，不在玩家附近直接出现，不允许屏幕外直接发动可命中冲刺，多只蓄力时间错开。

## 6. 阶段 C：远程型味真族

内部枚举 / 类名可使用 `RANGED_ENEMY`，界面暂名“撒味客（暂名）”。

状态循环：

1. **寻找射击位置**：移动到可达的中远距离视线位置，不永久保持最大距离，也不无限后退。
2. **瞄准**：举罐 / 摇晃或等价技术表现，地面明确标记目标；后半段锁定位置，允许玩家及时闪避。
3. **投射**：清楚、适中速度；被墙和厨房实体阻挡并消失，不伤害设施、不污染地面、不产生持续区域。
4. **射击循环 / 换位**：连续 2—3 发后更换角度；无射击线时重新寻找可达位置。
5. **被近身**：停止射击，短前摇后弱推击，随后硬直，硬直结束才重新找位。

战斗互动：

- 小炒穿透可命中远程型；战斧命中瞄准阶段可取消射击。
- 涮牛肉可以成为高权重目标；敌人需要移动到能看见诱饵的位置，攻击诱饵时不继续瞄准玩家，命中会消耗诱饵耐久。
- 目标选择不得写死为唯一玩家节点。当前建立轻量目标提供 / 评分接口，为未来多玩家、多目标和仇恨权重保留扩展点，但不实现网络同步。

## 7. 波次与生成

- 第一波后半首次出现少量速度型。
- 第二波首次出现 1 只远程型。
- 第三波混合基础型、重型、速度型和远程型；速度 / 远程较多时减少普通怪补充密度。
- 两种新行为不在开局同时展示。
- 波次内容、同场上限和掉落权重由集中配置驱动，不在敌人脚本复制随机逻辑。

## 8. 阶段 D：米袋与生米

- 正式初始食材柜增加一个完整米袋。
- 米袋的 `remaining_portions = 20` 存在具体 `ItemData` 实例中，显示 `20/20`。
- 每次交互只尝试创建一份 `1×1` 生米；依次走快捷栏兼容 / 空格与背包兼容 / 自动放置路由。
- 只有接收成功后才扣米袋数量；空间不足时不扣、不生成、不丢失。
- 空袋直接消失。本轮不创建包装垃圾、通用容器或一次性展开 20 个物品。
- 完整米袋作为世界掉落继续遵守快捷栏优先、背包后备、失败留地面的实际实例拾取规则。

## 9. 阶段 E：锅具水量与米饭烹饪

- 水不是物品，不进入快捷栏 / 背包 / 柜子。
- 兼容、干净且可装水的空锅具有离散 `water_units = 0 / 1 / 2`，水量属于锅具实例。
- 水池提供清楚的加水和倒水操作，不破坏洗盘、洗锅、ESC 或局部模态优先级；脏锅不能装水。
- 锅具及现有环形烹饪提示显示水量。
- 当前未完成阶段在停火或取走锅具 / 食材时归零并回到上一完成节点；已经投入的生米不返还。
- 锅巴是主动料理状态，不是失败标签；继续过热才加入既有焦糊标签。

## 10. 阶段 F：白米饭投掷武器

- 白米饭使用独立 `AttackForm.PROJECTILE` 配置，按住攻击键以约 0.3 秒间隔连续投掷饭团。
- 饭团快速但非瞬发，只命中第一个合法敌人，不穿透、无范围、无稳定击退 / 僵直，不伤玩家、友方或设施。
- 正常品质使用基础效果；完美首版只获得轻量伤害或速度提升，不实现终结技。
- 待摆盘白米饭可直接使用，未摆盘品质最高正常；首次消耗耐久后永久失去摆盘资格。
- 未摆盘耗尽直接消失；摆盘版本耗尽转为脏盘。

## 11. 阶段 G：白粥恢复料理

- 白粥使用集中定义的主要使用动作持续饮用，期间锁定移动和攻击，头顶条读取唯一饮用进度。
- 开始每份饮用时立即预扣 1 耐久；生命在完整 2 秒内连续恢复。松开或受到普通伤害立即中断，已恢复部分保留，未产生部分损失且耐久不退。
- 满生命不能启动；恢复不得超过生命上限。
- 完成煮制时获得实例级滚烫剩余时间。离开持续加热后开始冷却；摆盘不重置；快捷栏、背包和柜子中继续；真正暂停时停止。
- 滚烫饮用每份只触发一次 Prototype 烫伤。烫伤绕过护盾 / 锅巴、不打断当前饮用、最低保留 1 生命。
- 待摆盘白粥可饮用且最高正常；第一次饮用后不能摆盘；未摆盘耗尽消失，摆盘版本留下脏盘。

## 12. 阶段 H：锅巴防具与锅巴碎陷阱

### 自动装备

- 锅巴仅在快捷栏或玩家背包中生效；柜子、地面、工位和摆盘过程中不生效。
- 激活顺序为快捷栏左到右，其后背包按左上坐标从上到下、从左到右。
- 只应用第一个可用锅巴的减伤和耐久；破碎后下一个在后续伤害事件自动接替，同一次伤害不得链式消耗备用锅巴。
- UI / HUD 明确标记当前生效锅巴。

### 耐久与破碎

- 每个被无敌帧接受的有效伤害事件消耗 1 耐久；同一攻击 / 多碰撞体不能重复消耗，持续或多段伤害采用最短耐久扣除间隔。
- 首次承伤即 `has_been_used = true`，永久失去摆盘资格。
- 耐久归零只破碎一次：未摆盘锅巴直接移除，摆盘锅巴转为脏盘；同时在玩家位置生成锅巴碎陷阱。
- 烫伤不经过锅巴，也不消耗耐久。

### 锅巴碎陷阱

- 不阻挡移动和导航、不可拾取、不由普通投射物触发、不伤设施。
- 生成约 0.5 秒后完成布置；原持有者在离开范围前不会立即触发，离开后重新进入可以触发。
- 第一个有效敌人、玩家或具有实体碰撞的友方召唤触发并受伤，随后立即消失。
- 玩家承受碎片伤害时按当时的锅巴 → 护盾 → 生命管线处理。
- 跨波次保留；正式新局、退出与返回大厅统一清除。

## 13. 普通料理应急进食

- 新增 InputMap 语义动作 `secondary_use`，具体键位只是 Prototype 映射。
- 只有显式标记为 `emergency_edible` 的标准战斗料理使用通用规则；怪异料理默认不允许，白粥使用专职逻辑。
- 原地持续约 1.25 秒，期间锁移动 / 攻击；生命按进度实时恢复，松开或受击中断，已恢复部分不回滚。
- 开始时预扣最大耐久 50% 向上取整；剩余不足则消耗全部，并按实际支付比例缩放最大治疗。
- 满生命不能启动。接口必须可集中关闭或调参，本轮不统一调整旧料理耐久。

## 14. 输入与 UI 优先级

- 继续遵守 D-070 / D-071：最高层记录与退出确认 → 当前局部模态 → 全局暂停 → 普通操作。
- 背包、柜子、摆盘等局部 UI 的 ESC 先关闭自身；试玩记录与暂停菜单保持可恢复来源状态。
- 饮用和应急进食都使用玩家头顶进度条，取消、受击、切格、离开有效状态、打开模态或重置时立即清除。
- 新动作只通过 InputMap 集中定义，不在料理脚本中散落硬编码按键。

## 15. 自动与人工验收门

每阶段至少验证以下真实路径：

- A：真实伤害先盾后血、溢出、再次受击重置、暂停、波间只补盾、HUD 状态。
- B：追赶—蓄力—锁向—冲刺—差异后摇完整循环、一次命中、设施阻挡、诱饵换目标和拥挤防卡。
- C：找位—瞄准—锁点—发射—换位 / 近身推击、设施阻挡、诱饵转火、无视线重新寻路和同场上限。
- D：`3×4 / 4×3`、实例剩余量、成功才扣、空间不足原子失败、地面拾取、空袋和正式重置。
- E：水量 0 / 1 / 2、三条离散烹饪转换、阶段中断、洗盘 / 洗锅兼容。
- F：真实连续输入、首个目标、耐久 / 摆盘资格 / 盘子循环与阵营过滤。
- G：真实持续输入、实时治疗、取消 / 受击、预扣耐久、滚烫实例计时、暂停 / 实时 UI、烫伤例外。
- H：实际快捷栏 / 背包 / 柜子位置、稳定优先级、减伤与护盾顺序、一次耐久、破碎 / 脏盘、陷阱离开重入与敌我触发。

最终运行 0.1 至 0.6A 全部历史回归、0.6B 专项、Godot 4.6.2 资源扫描 / 脚本解析、主场景 Headless 自然启动，并在环境允许时检查 1280×720 普通窗口。内部函数测试只能补充边界，不能替代真实输入、真实伤害、真实节点和真实 UI 路径。

- 旧料理耐久整体重平衡、最终美术和正式音效。

## 17. 尚未确定，AI 不得补全

- 两类新味真族的正式名称和最终美术。
- 怪异料理是否可食用、如何治疗及其副作用。
- 现有和新增料理的最终耐久平衡。
- 盐对米饭、白粥与锅巴的具体效果。
- 米饭与青菜、牛肉的组合路线。
- 锅巴最终形状、品质数值和完整表现。
- 正式精英、波次奖励与长期掉落经济。

## 18. 人工试玩重点

- 30 护盾、4 秒延迟和 10 / 秒恢复是否提供容错但不会鼓励无限拖延。
- 速度型蓄力提示、锁向时点、设施碰撞与多只错峰是否可读。
- 远程型瞄准提示、弹速、换位频率和近身推击是否产生站位压力而非烦躁风筝。
- 新三波密度和两种同场上限是否合理。
- 米袋 `3×4`、20 份容量与正式初始 1 袋是否过强。
- 加水、离散节点和三种米饭结果是否容易理解。
- 白米饭续航、白粥风险回报、滚烫提示和锅巴自动装备顺序是否直观。
- 锅巴碎友伤是否产生清楚的欢乐风险，而不是不可理解的无提示伤害。
