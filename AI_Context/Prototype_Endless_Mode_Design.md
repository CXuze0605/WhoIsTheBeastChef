# 无尽试炼第一版设计（2026-07-30）

## 状态

- 模式方向与核心结构已确认。
- 以下预算、倍率、成本和上限均为 Prototype 起点，需要用真实长局数据调整。
- 本模式用于数值测试和长期挑战，不替换现有固定三波单机模式。

## 核心目标

无尽模式应持续增加压力，同时给玩家理解新敌人、调整料理和整理资源的空间。难度来自敌人组合、连续压力、资源取舍和有限的后期属性成长，而不是突然包围、不可读的攻速或隐藏动态放水。

## 五波压力周期

每五波为一个周期：

1. 适应波：较低压力，展示本周期变化。
2. 强化波：强化一种明确压力。
3. 混合波：组合两种压力。
4. 高峰波：允许完整混合，周期最高压力。
5. 缓冲波：预算回落、准备时间略增，但仍是正常战斗波。

下一周期的整体基线高于上一周期。

## 前五波

- 第1波：普通型为主。
- 第2波：首次正式加入速度型。
- 第3波：首次正式加入重型。
- 第4波：首次正式加入远程型。
- 第5波：四类低强度混合。

新压力第一次出现时，不同时引入另一种全新敌人。

## 威胁预算

Prototype 成本：

| 类型 | 成本 |
|---|---:|
| 普通型 | 1.0 |
| 速度型 | 1.6 |
| 远程型 | 2.2 |
| 重型 | 3.0 |

波次总预算决定整波敌人总量；场上威胁上限决定同一时刻允许存在的压力。预算不足时不生成超额敌人，允许最后一个合法单位造成小范围向上取整，但必须记录实际预算。

周期内建议倍率：`0.90 / 1.00 / 1.10 / 1.25 / 0.95`。每进入一个五波周期，基础预算线性增加。所有参数集中在权威配置，不散落于 UI 或敌人脚本。

## 场上压力

- 初期场上威胁上限约 7～9。
- 中期逐步提高到 12～15。
- 单人 Prototype 性能安全上限约 18。
- 达到上限后下一批保留在队列中并延迟，不删除、不换弱怪。
- 速度型同场上限暂为4，远程型暂为2，重型建议暂为2。
- 速度、远程、重型不能同时占满各自上限。

## 波次主题

主题池：

- 人潮型：普通型为主。
- 突袭型：速度型比例提高。
- 重压型：重型搭配普通型。
- 压制型：远程型搭配普通型。
- 混合型：完整组合，用于高峰波。
- 缓冲型：普通型较多，特殊敌人较少。

约束：

- 同主题不能连续出现三次。
- 高压主题后提高缓冲主题权重。
- 周期第4波优先混合型。
- 周期第5波从缓冲主题池选择。
- 记录最近至少三波主题。

## 提前情报

整波计划必须在波间准备开始时生成并锁定。玩家应能看到：

- 波次与主题。
- 预计敌人类型。
- “大量/若干/少量”等模糊数量。
- 单方向、交替双方向或同时双方向等压力提示。

不得等准备结束后才随机敌人组合。

## 生成方向

- 前五波每个小批次只从一个方向进入。
- 第二周期开始允许两个方向交替。
- 中期高峰波允许两个方向同时施压。
- 第一版不让普通波次从三四个方向同时包围。
- 保留全局预警、局部方向预警、合法点、最小距离与分批错峰。

## 后期成长

- 第1～10波主要增加数量、组合、方向和连续性，不强化基础属性。
- 第11～25波缓慢增加生命、场上预算和特殊敌人比例。
- 第26波后数量接近安全上限，主要通过组合、间隔、生命和小幅伤害增长。
- Prototype 起点：第10波后每五波生命约 `+8%`，直接伤害约 `+4%`。
- 移速、攻击前摇、弹道速度和击退原则上不随波次无限成长。
- 波次强化与浪费强化采用加法汇总，不复利相乘。

## 资源闭环

- 继续使用现有四类敌人掉落和短缺补偿。
- 解锁对应敌人后，每五波周期必须存在获取米、牛肉和基础调味的理论机会。
- 玩家仍需亲自拾取，短缺补偿不直接送入背包。
- 缓冲波可以提高资源型敌人或基础掉落机会，但第一版不发免费奖励箱。

## 公平性

无尽模式不因玩家残血、低库存或表现较差而暗中降低预算、伤害或敌人类型。允许的安全调度只有：

- 场上威胁达到上限时延迟。
- 无合法生成点时重新选择或等待。
- 暂停时冻结。
- 类型达到同场上限时保留在生成队列。

## 随机种子与统计

支持随机种子；同一配置与种子应产生相同主题、敌人组合和生成方向。

`RunStats` 至少增加：

- 最高波次、存活时间。
- 每波预算、主题、组合、方向和完成时间。
- 各敌人生成/复味数量。
- 每波生命/护盾伤害。
- 各料理制作、使用、伤害与剩余耐久。
- 食材获得、消耗、腐败、丢弃与波末库存。
- 短缺补偿事件。
- 最终死亡来源与随机种子。

## 验收边界

- 固定三波模式行为不变。
- 无尽模式能独立进入、无限推进、失败结算和返回大厅。
- 前五波引导顺序、五波周期、主题防重复和缓冲波正确。
- 总预算、场上预算、类型上限和排队延迟正确。
- 情报在准备阶段锁定且与实际生成一致。
- 同种子可复现。
- 正式重置清理全部无尽队列、统计、敌人、掉落与强化状态。
