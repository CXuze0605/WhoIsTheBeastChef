## D-001：项目名称与双关方向

- 日期：2026-07-18
- 状态：已确认
- 决策：中文名为《谁是大厨生》；英文暂定名为 Who's the Beast Chef?
- 理由：中文利用“大厨生 / 大畜生”谐音；英文重点利用 **Best / Beast 的近音双关**，从 Best Chef 转向 Beast Chef，表达“最佳厨师”与“厨房野兽”的喜剧反差，而不是简单对应 Chef 和 Beast 的词义。
- 影响：对外文案和视觉设计应保留“厨师与野兽”的喜剧反差。英文名仍允许在正式发布前复核商标、搜索性和英语表达。

## D-002：游戏类型与核心循环

- 日期：2026-07-18
- 状态：已确认
- 决策：采用 2D 俯视角“烹饪 + 战斗 + 轻度策略”；核心循环为收集食材 → 制作料理 → 把料理作为核心资源影响战局 → 抵御敌人。
- 理由：项目核心创新是让烹饪决定战斗方式，而不是将做饭作为独立附属系统。
- 影响：任何战斗、配方或资源设计都必须维护烹饪和战斗之间的直接因果关系。

## D-003：第一版目标与范围

- 日期：2026-07-18
- 状态：已确认
- 决策：2026 年 9 月左右完成一版可用于游戏开发实习作品集的完整 Demo；首版只包含一个角色、少量食材、2 至 3 种料理、少量敌人和完整胜负流程。
- 理由：两人团队且主开发者采用边做边学的方式，需要优先保证完成度和可展示性。
- 影响：首版不做联机、大型肉鸽、大地图、复杂剧情、大量角色和经营系统。

## D-004：混乱体验的质量标准

- 日期：2026-07-19
- 状态：已确认
- 决策：混乱必须由简单规则、时间压力、空间与任务冲突自然产生；失败要可读、有补救空间并倾向产生欢乐，而不是依赖隐藏规则或随机惩罚。
- 理由：项目希望玩家说“哈哈怎么又炸了”，而不是认为系统恶意或繁琐。
- 影响：每个压力机制必须同时设计提示、反馈和恢复方式。

## D-015：玩家亲自战斗，战斗与烹饪同时进行

- 日期：2026-07-19
- 状态：已正式确认
- 决策：玩家亲自参与战斗，战斗过程中厨房持续开放；玩家同时管理战斗、锅具、切配、食材、烹饪、料理补充、盘子、腐败、厨房事故与构筑。料理决定玩家战斗方式，可形成近战装备、远程装备、炮台、陷阱、召唤物、主动技能、范围增益、防御能力、回复能力或特殊规则型效果。
- 理由：项目不是“完成料理后进入战斗”，也不是玩家在厨房后方进行自动指挥；核心压力来自“现在应该战斗，还是先处理厨房”。
- 影响：炮台和召唤物只是分支，料理不能被实现为唯一的自动战斗主体；战斗系统必须为持续烹饪留出决策与操作空间。

## D-016：核心主题、味能、味真族与食补方向

- 日期：2026-07-19
- 状态：已正式确认（部分名称待定）
- 决策：游戏核心表达为“天大地大，吃饭最大。”战斗具有医疗和拯救性质，旨在帮助敌人恢复正常味觉、身体状态和满足感，而不只是消灭敌人。世界力量暂称“味能”；食材经加工、烹饪、组合与调味后形成稳定味能。敌人统称“味真族”，目前确认存在两类异化方向：一类来自极端审美压力、长期节食、作息与三餐紊乱、敷衍饮食和营养不良；另一类来自暴饮暴食、无节制追求刺激和无法感知正常饥饱。
- 理由：主题关注身体需求、合理规律适量的饮食，以及人与食物的健康关系；批判的是失衡状态、审美压力和不健康生活方式，不是嘲笑瘦人、胖人或现实中的进食障碍患者。
- 长期扩展方向：食补可在中后期用于调节状态、缓解构筑副作用、处理味觉疲劳、持续恢复与强调均衡饮食，不进入首版 Demo 核心。
- 影响：“味能”仍是暂称；两类味真族的正式分类名称待定；“击杀”未来可能改为“复味”或“调和”，具体名称继续列为待决策，不得擅自确定。

## D-017：准备阶段、战斗阶段与波次循环

- 日期：2026-07-19
- 状态：已正式确认
- 决策：循环为“准备阶段 → 战斗开始 → 战斗与烹饪同时进行 → 完成本轮味真族的复味 → 波次结算与成长选择 → 下一轮准备”。准备阶段用于查看敌人、整理背包、获取有限初始食材、提前处理部分食材、制作初始料理并形成初步构筑，但不能提前完成整轮战斗资源。
- 理由：准备阶段提供计划，战斗阶段保持即时压力，两者共同支持实时构筑。
- 影响：具体波次奖励系统尚未确定，禁止在确认前自行实现。

## D-018：Demo 采用轻量化有限背包

- 日期：2026-07-19
- 状态：已正式确认（参数待定）
- 决策：背包格子有限；食材、半成品、料理、盘子和腐败物都会占用空间，用于制造路线规划、加工顺序和临场取舍；玩家可以在背包界面进行摆盘。

## D-019：新鲜度、腐败、厨余处理与局外回收

- 日期：2026-07-19
- 状态：已正式确认；冰柜升级、堆肥桶与菜园为长期扩展方向
- 决策：食材新鲜度随局内时间下降、效果逐渐降低并最终转化为腐败物。腐败物无料理效果、不能使用任何烹饪方式、不能通过加工恢复，仍占据背包、库存或台面格子，必须由玩家花时间处理。厨余垃圾桶可以快速清除腐败物并腾出空间，但会触发“浪费粮食”并小幅增强味真族力量。
- 理由：腐败把时间压力与背包空间连接起来，并让快速清理具有代价。
- 长期扩展方向：局外冰柜升级可延缓腐败；堆肥桶一次只能处理一份腐败物，转化完成前不能放入下一份，收益用于加速局外菜园蔬菜成长；堆肥不得使故意放坏食材成为最优策略。菜园当前只确认可种蔬菜且受堆肥加速。
- 影响：冰柜容量、保鲜倍率和升级结构；垃圾桶增强当前敌人、下一波敌人或公共压力值等具体表现；菜园资源、周期、带入和升级方式均尚未确定，不得由 Codex 自行决定。

## D-020：自由烹饪与离散状态节点

- 日期：2026-07-19
- 状态：已正式确认
- 决策：游戏采用符合现实烹饪逻辑的自由组合，不采用完全固定菜谱。玩家可自由选择食材、切配、烹饪方式、加工顺序与是否调味；允许少量危险料理，但必须有形成原因、收益与副作用。Demo 包含煎、炒、煮、炸，并用离散状态节点记录过程：只有达到明确时间节点才转化；提前取出回到上一个已完成状态，未完成阶段进度不保留，再次放入后重新计算该阶段时间。
- 理由：自由组合支持发现与构筑，离散状态便于理解、设计、实现和反馈。
- 影响：状态应表达为“生肉 → 半熟 → 完成 → 焦糊”等明确节点，而不是“煎了 37%”。

## D-021：牛肉加工、补救、失败标签与品质临时方案

- 日期：2026-07-19
- 状态：加工与标签规则已正式确认；品质降级为 Demo 临时方案
- 决策：牛肉是第一个完整设计样本；不可逆路线为“整块生牛肉 → 切一次 → 生牛排 → 再次切 → 生牛肉片”。整块牛肉直接煎或炒，中等时间后变为“大肉块【外焦里生】”，继续加热变为焦炭；直接炸，较短时间后变为“外焦里熟的大肉块”，继续加热变为焦炭；直接煮，中等时间后变为“外熟里生的牛肉”，长时间后变为“水煮大块牛肉”。焦炭不可食用、不可加工回正常料理，但可投掷并造成一次性伤害。
- 补救规则：“大肉块【外焦里生】”直接再次加热只能变焦炭；切一次变为继承【外焦里生】的半熟牛排，再切一次变为继承该标签的半熟牛肉片。半熟牛排合理煎制后成为仍保留标签的煎牛排；过度加热增加【焦糊】标签；再继续加热成为焦炭。
- 标签与品质：命名采用“基础物品名称 + 状态或失败标签”；已确认标签为【外焦里生】与【焦糊】。料理品质分完美、正常、瑕疵、糟糕四档。
- Demo 临时方案：无失败标签的正常成品默认为正常；每个失败标签降低一级品质，标签可累积，补救不会移除标签，品质最低为糟糕；0 个标签为正常、1 个为瑕疵、2 个及以上为糟糕。
- 长期扩展方向：不同失败标签可以拥有独立效果，但首版暂不实现。

## D-027：小炒黄牛肉组合路线与料理身份判定原则

- 日期：2026-07-19
- 状态：已正式确认（部分失败标签与调味效果待定）
- 决策：小炒黄牛肉的基础路线为“整块生牛肉 → 生牛排 → 生牛肉片 → 使用腌肉料腌制 → 腌牛肉片 → 炒锅先加油 → 放入腌牛肉片 → 短时间炒制 → 加入辣椒段 → 继续炒制 → 小炒黄牛肉”。它是组合料理，不是牛肉单独炒熟后自动形成的料理。
- 成菜条件：牛肉必须切成牛肉片、使用腌肉料完成腌制、炒锅提前加油、牛肉片先短时间炒制、随后加入辣椒段并完成后续炒制。
- 通用原则：主食材、关键配菜和核心工序决定“做出了什么料理”；普通调味品主要决定“料理具有什么属性”。盐等普通调味品不影响是否形成小炒黄牛肉，只影响成品属性、构筑效果或品质倾向。早期记录曾以生抽举例，但 Prototype 0.2.1 明确第一版不加入生抽。
- 错误分支：未加油炒制会使牛肉直接变为不可补救的焦炭，并使炒锅进入【粘锅】状态、停止烹饪；未腌制仍可成菜，但获得未命名失败标签并降低品质；辣椒段加入过早仍可成菜，但获得未命名失败标签并降低品质；炒制过久获得【焦糊】或对应过火失败标签，继续长时间加热最终成为焦炭。
- 影响：未腌制标签名称、辣椒段过早标签名称及独立效果、过火分支最终采用的标签，以及普通调味品的具体属性影响均保持待决策，不得自行补全。

## D-053：首波开始前使用无倒计时自由准备

## D-054：两个通用灶位承载三种可移动锅具

## D-055：战斧牛排可直接近战或在首次使用前装盘

## D-056：盐与芥末复用主动调味数据扩展到战斧牛排

## D-057：一份生牛肉片保存五个可单独涮煮的份数

- 决策：生牛肉片实例保存 `remaining_portions = 5`。进入炒锅时整份消耗；进入汤锅时每次只扣一片。汤锅保留热水并一次处理一片，涮肉按失败状态安全堆叠，最多五片一格。

## D-058：涮牛肉是单目标锁定的诱食陷阱

- 日期：2026-07-21
- 状态：已确认并实现；范围、伤害、停顿和锁定超时为 Prototype 临时值
- 决策：涮牛肉可放置在合法地面，一片只被一个味真族锁定。锁定者暂时放弃玩家、寻路、品尝并受到一次复味伤害；锁定者失效或超时则释放锁定。
- 影响：未锁定陷阱可拾回；玩家和友方不会触发。陷阱跨波次和波间保留，只在整局重启清理；煮烂牛肉不能作为正常陷阱。
