## D-016：核心主题、味能、味真族与食补方向

- 日期：2026-07-19
- 状态：已正式确认（部分名称待定）
- 决策：游戏核心表达为“天大地大，吃饭最大。”战斗具有医疗和拯救性质，旨在帮助敌人恢复正常味觉、身体状态和满足感，而不只是消灭敌人。世界力量暂称“味能”；食材经加工、烹饪、组合与调味后形成稳定味能。敌人统称“味真族”，目前确认存在两类异化方向：一类来自极端审美压力、长期节食、作息与三餐紊乱、敷衍饮食和营养不良；另一类来自暴饮暴食、无节制追求刺激和无法感知正常饥饱。

- 长期扩展方向：食补可在中后期用于调节状态、缓解构筑副作用、处理味觉疲劳、持续恢复与强调均衡饮食，不进入首版 Demo 核心。
- 影响：“味能”仍是暂称；两类味真族的正式分类名称待定；“击杀”未来可能改为“复味”或“调和”，具体名称继续列为待决策，不得擅自确定。

## D-019：新鲜度、腐败、厨余处理与局外回收

- 日期：2026-07-19
- 状态：已正式确认；冰柜升级、堆肥桶与菜园为长期扩展方向
- 决策：食材新鲜度随局内时间下降、效果逐渐降低并最终转化为腐败物。腐败物无料理效果、不能使用任何烹饪方式、不能通过加工恢复，仍占据背包、库存或台面格子，必须由玩家花时间处理。厨余垃圾桶可以快速清除腐败物并腾出空间，但会触发“浪费粮食”并小幅增强味真族力量。
- 理由：腐败把时间压力与背包空间连接起来，并让快速清理具有代价。
- 长期扩展方向：局外冰柜升级可延缓腐败；堆肥桶一次只能处理一份腐败物，转化完成前不能放入下一份，收益用于加速局外菜园蔬菜成长；堆肥不得使故意放坏食材成为最优策略。菜园当前只确认可种蔬菜且受堆肥加速。
- 影响：冰柜容量、保鲜倍率和升级结构；垃圾桶增强当前敌人、下一波敌人或公共压力值等具体表现；菜园资源、周期、带入和升级方式均尚未确定，不得由 Codex 自行决定。

## D-020：自由烹饪与离散状态节点

## D-021：牛肉加工、补救、失败标签与品质临时方案

- 日期：2026-07-19
- 状态：加工与标签规则已正式确认；品质降级为 Demo 临时方案
- 决策：牛肉是第一个完整设计样本；不可逆路线为“整块生牛肉 → 切一次 → 生牛排 → 再次切 → 生牛肉片”。整块牛肉直接煎或炒，中等时间后变为“大肉块【外焦里生】”，继续加热变为焦炭；直接炸，较短时间后变为“外焦里熟的大肉块”，继续加热变为焦炭；直接煮，中等时间后变为“外熟里生的牛肉”，长时间后变为“水煮大块牛肉”。焦炭不可食用、不可加工回正常料理，但可投掷并造成一次性伤害。
- 补救规则：“大肉块【外焦里生】”直接再次加热只能变焦炭；切一次变为继承【外焦里生】的半熟牛排，再切一次变为继承该标签的半熟牛肉片。半熟牛排合理煎制后成为仍保留标签的煎牛排；过度加热增加【焦糊】标签；再继续加热成为焦炭。
- 标签与品质：命名采用“基础物品名称 + 状态或失败标签”；已确认标签为【外焦里生】与【焦糊】。料理品质分完美、正常、瑕疵、糟糕四档。
- Demo 临时方案：无失败标签的正常成品默认为正常；每个失败标签降低一级品质，标签可累积，补救不会移除标签，品质最低为糟糕；0 个标签为正常、1 个为瑕疵、2 个及以上为糟糕。
- 长期扩展方向：不同失败标签可以拥有独立效果，但首版暂不实现。
- 影响：“外焦里熟的大肉块”的料理分类及“外熟里生”是否成为正式失败标签仍未确定；生牛排的四种路线、生牛肉片除 D-027“小炒黄牛肉”外的其他路线与单独加热状态、其他组合、调味与战斗形态必须继续讨论，不能自行补全。

## D-022：主动摆盘、QTE 与盘子循环

- 日期：2026-07-19
- 状态：已正式确认
- 决策：玩家在背包内主动摆盘；一旦开始摆盘，料理彻底定型，不能再切配、加热、调味、加入食材或修改。摆盘消耗一个干净盘子并与待定型料理合并，完成后只占一个背包格。干净盘子和脏盘子均每 4 个堆叠为一格；料理被食用、投掷、部署或消耗后留下一个脏盘子。
- QTE 当前倾向：无失败标签的料理普通完成为正常，命中完美区间提升为完美；失败标签不能由 QTE 清除。QTE 对失败料理是否有额外影响、QTE 失败是否仅失去完美奖励，均尚未确认。
- 水池规则：脏盘数量无上限；玩家在水池旁持续按住交互键清洗且不能移动，可随时松手取消，松手使当前盘进度归零；洗完立即产出干净盘并在持续按住时自动清洗下一盘。干净盘进入无上限的盘子堆，由玩家主动拿取。
- Demo 清洗速度：1 个为基础速度，2 至 4 个稍快，5 至 8 个明显加快，9 个及以上最高。开始一轮连续清洗时按当时脏盘数量锁定档位；持续按住期间即使数量下降也不降速；松手结束本轮，下次按新数量重算。
- 理由：摆盘构成料理定型边界，盘子循环为厨房压力和资源管理提供可读任务。
- 影响：摆盘不是固定工作台；移动或战斗中摆盘的具体操作限制需要试玩调整，QTE 未决规则不得擅自确定。

## D-027：小炒黄牛肉组合路线与料理身份判定原则

- 日期：2026-07-19
- 状态：已正式确认（部分失败标签与调味效果待定）
- 决策：小炒黄牛肉的基础路线为“整块生牛肉 → 生牛排 → 生牛肉片 → 使用腌肉料腌制 → 腌牛肉片 → 炒锅先加油 → 放入腌牛肉片 → 短时间炒制 → 加入辣椒段 → 继续炒制 → 小炒黄牛肉”。它是组合料理，不是牛肉单独炒熟后自动形成的料理。
- 成菜条件：牛肉必须切成牛肉片、使用腌肉料完成腌制、炒锅提前加油、牛肉片先短时间炒制、随后加入辣椒段并完成后续炒制。
- 通用原则：主食材、关键配菜和核心工序决定“做出了什么料理”；普通调味品主要决定“料理具有什么属性”。盐等普通调味品不影响是否形成小炒黄牛肉，只影响成品属性、构筑效果或品质倾向。早期记录曾以生抽举例，但 Prototype 0.2.1 明确第一版不加入生抽。
- 错误分支：未加油炒制会使牛肉直接变为不可补救的焦炭，并使炒锅进入【粘锅】状态、停止烹饪；未腌制仍可成菜，但获得未命名失败标签并降低品质；辣椒段加入过早仍可成菜，但获得未命名失败标签并降低品质；炒制过久获得【焦糊】或对应过火失败标签，继续长时间加热最终成为焦炭。
- 影响：未腌制标签名称、辣椒段过早标签名称及独立效果、过火分支最终采用的标签，以及普通调味品的具体属性影响均保持待决策，不得自行补全。
