# Prompt Templates

`AGENTS.md` 负责长期协作规则；本文件用于说明单次任务。无需每次填写所有字段；未知信息可写“未知，由 AI 先只读定位”。模板中的范围可以是文件、功能、场景、报错或玩家操作路径，不要求负责人预先定位代码。证据不足时，AI 按 `AGENTS.md` 由窄到宽调查，并在扩大范围前说明原因。

