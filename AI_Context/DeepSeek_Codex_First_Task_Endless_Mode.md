## 交付策略

优先分两步，避免一次性大改：

1. 数据与导演：模式枚举、预算计划、主题、种子、生成队列和专项测试。
2. UI 与完整流程：入口、提前情报、结算、重置和普通窗口验收。

每一步都必须保持固定三波模式回归通过。

## 验收

- 固定三波模式无回归。
- 无尽模式可持续推进并在失败后正确结算、返回大厅。
- 前五波、五波节奏、主题防重复、缓冲波和提前情报符合设计。
- 达到场上上限时敌人排队，不被删除或替换。
- 类型并发上限正确。
- 相同种子可复现至少前15波计划。
- 重置后无残留敌人、掉落、队列、统计或强化。
- 新增专项测试，并运行所有受影响的既有回归。
